ASET TANAH DAN KENDARAAN WEB V17.8

Perubahan utama:
1. Status sinkronisasi dapat diklik untuk melihat persen, nama data, jumlah selesai, antrean, dan pesan kendala.
2. Sinkronisasi berjalan per kelompok kecil agar progres terlihat dan kegagalan dapat diketahui.
3. Pejabat disimpan sebagai snapshot pada surat sehingga nama, NIP, dan jabatan tidak kosong pada preview lokal.
4. Perubahan Master Pejabat/Pengguna/Pengaturan langsung memperbarui cache browser.
5. Riwayat surat pertama kali mengambil data form ringan, lalu preview berikutnya memakai cache lokal tanpa membuat Google Docs.
6. Template surat lokal disesuaikan dengan TEMPLATE_SURAT_REKOMENDASI_STNK_BPKPD dan template tanda terima BPKB.
7. Data kendaraan/tanah disimpan juga di memori browser selama sesi agar pindah dashboard, daftar, detail, dan form lebih cepat.

Penerapan:
- Upload semua isi folder ini ke root repository Cloudflare Pages.
- Pastikan index.html, assets, templates, functions, dan sw.js berada langsung di root.
- Tunggu deployment lalu buka web dan tekan Ctrl+F5 satu kali.
- Klik indikator status di kanan atas untuk membuka rincian sinkronisasi.
