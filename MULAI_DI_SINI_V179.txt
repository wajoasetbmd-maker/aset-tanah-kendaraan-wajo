WEB V17.9 — CACHE CEPAT, PENYIMPANAN ONLINE

1. Upload seluruh isi paket ke root repository Cloudflare Pages.
2. Tambahkan BACKEND_APPS_SCRIPT/WebV179Upgrade.gs ke project Apps Script.
3. Jalankan upgradeWebV179OnlineLetters.
4. Jalankan diagnoseWebV179OnlineLetters dan pastikan ok:true.
5. Deploy Apps Script: Manage deployments > Edit > New version > Deploy.
6. Tunggu Cloudflare Pages selesai, lalu Ctrl+F5.
